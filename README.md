# Teranga Blog

Mini-blog multipage en React : lecture d'articles, auteurs, commentaires et favoris.

Site en ligne : https://teranga-blog-nine.vercel.app/
Dépôt GitHub : https://github.com/Ndeye-Madeleine/teranga-blog

## Lancer le projet

npm install
npm run dev

## Trois choses que j'ai apprises

1. Une prop ne se modifie jamais.
2. Dans une liste, on utilise l'id comme clé et pas l'index.
3. fetch ne signale pas une erreur 404 tout seul, il faut tester reponse.ok.
